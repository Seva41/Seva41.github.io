Antes de SyncDisp escribí las herramientas con que se enseña seguridad en la UAI, y sigo aportando a proyectos que uso. Before SyncDisp I wrote the tools used to teach security at UAI, and I keep contributing to projects I use.

  • LabCentral Flask · Next.js · Docker

    Plataforma para cursos de seguridad: cada ejercicio corre en su propio contenedor por estudiante, con trabajo en equipo, cuestionarios y puntaje. A platform for security courses: each exercise runs in its own container per student, with team work, quizzes and scoring.

  • Desafíos CTFCTF challenges Python · Bash

    Para Seguridad en TI de la UAI: SSH, sniffing y firewall, inyección SQL, XSS y robo de sesión, hashing y cifrado, y la Hackatón CTF UAI 2025 en Viña del Mar. For UAI's IT Security course: SSH, sniffing and firewalls, SQL injection, XSS and session hijacking, hashing and ciphers, and the UAI 2025 CTF Hackathon in Viña del Mar.

  • Control de ingresoAccess control Laboratorio UAIUAI lab

    Control de acceso dinámico con registro de asistencia para el Laboratorio de Ciberseguridad de la UAI. Dynamic access control with attendance logging for the UAI Cybersecurity Lab.

  • YouTube No Translation TypeScript · Safari

    Cuatro contribuciones aceptadas en esta extensión con más de 1.200 estrellas: compatibilidad con Safari, el proyecto de Xcode y la traducción al español. Four merged contributions to this extension with over 1,200 stars: Safari support, the Xcode project and the Spanish translation.

  • Pi-hole Bash

    Un mensaje de error más claro cuando una lista de bloqueo usa un protocolo inválido. A clearer error message when a blocklist uses an invalid protocol.
